Play at https://survival.longtt.site/ — download the native client for your computer.

- [Windows x64 (75.1 MB)](https://github.com/longtt2705/PokemonSurvival-Downloads/releases/download/v0.1.0-df65e04/PokemonSurvival-Windows-x86_64.zip)
- [macOS — Apple Silicon and Intel (96.6 MB)](https://github.com/longtt2705/PokemonSurvival-Downloads/releases/download/v0.1.0-df65e04/PokemonSurvival-macOS-universal.zip)
- [SHA-256 checksums](https://github.com/longtt2705/PokemonSurvival-Downloads/releases/download/v0.1.0-df65e04/SHA256SUMS.txt)

Extract the whole ZIP, then open `PokemonSurvival.exe` or `PokemonSurvival.app`. Both connect to the game server automatically. Sign in or register, then create a world or join a friend's invite code. Progress is stored on the server.

Windows is unsigned. The macOS app is ad-hoc signed and not notarized; its first launch may require **System Settings → Privacy & Security → Open Anyway**.

Version 0.1.0, build `df65e04`, protocol 15. This repository contains downloadable client releases only. Game source code is maintained separately.
