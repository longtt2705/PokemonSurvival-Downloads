# Pokémon Survival downloads

Download and play at https://survival.longtt.site/.

- [Windows x64 ZIP](https://github.com/longtt2705/PokemonSurvival-Downloads/releases/latest/download/PokemonSurvival-Windows-x86_64.zip)
- [macOS ZIP — Apple Silicon and Intel](https://github.com/longtt2705/PokemonSurvival-Downloads/releases/latest/download/PokemonSurvival-macOS-universal.zip)
- [SHA-256 checksums](https://github.com/longtt2705/PokemonSurvival-Downloads/releases/latest/download/SHA256SUMS.txt)
- [Build information](https://github.com/longtt2705/PokemonSurvival-Downloads/releases/latest/download/release-manifest.json)

These links follow the latest complete published build automatically.

Extract the whole ZIP, then open `PokemonSurvival.exe` or `PokemonSurvival.app`.
Both connect to the game server automatically. Sign in or register, then create
a world or join a friend's invite code. Progress is stored on the server.

Windows is unsigned. The macOS app is ad-hoc signed and not notarized; its first
launch may require **System Settings → Privacy & Security → Open Anyway**.

This repository contains downloadable client releases only. Game source code
is maintained separately. Older builds remain available on the Releases page.
